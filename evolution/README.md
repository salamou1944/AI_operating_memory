# Evolution Engine — Evidence-Gated Promotion

This directory turns the Evolution Frontier contract into an executable gate.

Pipeline: Observe → Research → Discover Gap → Hypothesize → Generate Mutations → Sandbox → Attack → Verify → Learn → Promote → Deploy → Observe

The promotion boundary rejects insufficient candidate diversity, missing immutable baseline/sandbox evidence, regressions, non-independent verification, failed security/boundary metrics, unknown project identifiers, tampered evidence hashes, and decisions other than PROMOTE.

Trust levels: L0 idea → L1 code → L2 deterministic tests → L3 independent verification → L4 repeated/adversarial verification → L5 deployed observation.

Synthetic tests, provider reachability, or affiliate URLs never constitute revenue evidence.

Verification: node evolution/test-validator.mjs

The validator is dependency-free and fail-closed.
