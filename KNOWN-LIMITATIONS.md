# Known Limitations

- A skill cannot grant itself a permission that its connected tool does not provide.
- Browser automation can fail on MFA, CAPTCHA, device checks, or anti-bot controls; these must be handled through supported user interaction, not bypassed.
- External services can change APIs, pricing, eligibility, or terms; current state must be rechecked before material decisions.
- Autonomous execution does not mean unrestricted execution: destructive, financial, legal, security-sensitive, or public irreversible actions may require explicit approval.
- Repository write access must be verified by an actual write operation, not inferred from UI settings alone.
