# Knowledge Route Catalog

This catalog stores reusable, provider-neutral routes discovered from canonical Skills, AI Operating Memory, project assets, and Collection provenance.

## Rules

- A route is reusable only after independent verification.
- Collection is provenance/discovery, not execution proof.
- Prefer existing verified Skills/assets before new implementation.
- Prefer free/local/provider-neutral paths when they satisfy the outcome.
- Every verified route must identify its owning repository and verification evidence.
- Do not store secrets, credentials, or unrestricted offensive procedures here.

## Canonical route classes

1. REUSE — existing verified Skill/asset closes the task.
2. UPGRADE — an existing Skill/asset needs a verified improvement.
3. FREE_LOCAL — a free/local route closes the task without new spend.
4. PROVIDER_ROUTE — provider selection/fallback is required.
5. NEW — no existing route closes the actual gap.
