# Cinematic Video Signal

LTX-2.5/LTX Desktop is a useful capability signal for the project.

Verified characteristics:
- text-to-video
- image-to-video
- audio-to-video
- local generation on supported hardware
- API mode for unsupported hardware
- LoRA support for local generation
- integrated video editing workflow

Architecture to retain:
- modality-aware provider routing
- local-first when appropriate
- provider/API fallback
- asset provenance
- product/character identity protection
- artifact validation
- reproducible evidence
- cost and latency accounting

Integration:
- MONY: short-form creative production and variant testing.
- EASY: product creative video with Product DNA/Product Integrity enforcement.
- Elite/ARMY-14: provider capability discovery, execution evidence, validation and fail-closed routing.

LTX remains an optional provider/capability, not a mandatory dependency.
